# 公開準備

## README

- 論文の図表番号と、それを再生成するコマンドの対応を書く。
- 環境構築は `uv sync` から始まる形で書く。
- クローンから図表の再生成まで、README に書いたコマンドだけで通ることを確認する。

## 配布

- データセットと訓練済みモデルの取得手段を用意する。リポジトリに入らない大きさのものは、
  配布先からの取得コマンドを README に書く。
- データセットを生成できる場合は、生成スクリプトも残す。

## 公開前の確認

- 認証情報、未公開データ、内部メモ、絶対パス、著者以外の個人情報が含まれていないか。
- LICENSE と引用情報 (bibtex) があるか。
