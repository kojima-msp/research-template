# 添削

英語を良くする作業ではなく、意味を変えずに、読者が推測しなくて済む形にする作業。
書き方の基準は `paper` skill と `paper/house-style.md` を使う。

## 直していいもの

文法、冠詞、前置詞、句読点、誤字、意味の変わらない言い換え、冗長の削除、定義済みの
用語の統一。edit で `paper/main.tex` に当てる。説明を添えない。

文を単独で直さない。段落の機能を 1 つ決め、各文がそれを支えているかを見てから直す。
文の分割、段落の分割・統合・順序変更は、主張と根拠、結果と条件、定義と記号、引用と
対象の文を引き離さない範囲でだけ行う。

## 著者に返すもの

直さずに、原文を残して指摘する。

- 主張の強さ、法助動詞、因果、普遍性、比較の範囲
- 仮定、条件、否定、量化子
- 理論的な位置づけ、数値の解釈
- 引用の帰属、定義・記法・アルゴリズムの意味、貢献の境界
- 足りない前提・根拠・限界

文法的に直せない文も、原文を残して指摘する。足りない論理を書いて埋めない。

## 指摘の書き方

- 該当箇所、何が問題か、なぜ問題か、著者に決めてほしいこと、の順で書く。
- 同じ答えで解決するものはまとめる。迷ったら分ける。該当箇所は全部挙げる。
- 原稿から示せること、著者に聞かないと決まらないこと、手元の材料では判断できないことを
  区別する。図表が確認できないことは、主張が誤りである根拠ではない。
- 原稿に紐づけて書く。書き手の能力を評価しない。

## 触らないもの

数式、数値、単位、引用コマンドとキー、`\label` と参照、マクロ定義、未知のコマンド、
環境名、コメント。節見出し・キャプション・箇条書きの中の散文は直してよい。

直し終えたら、英語を良くしないで意味だけを比較する。主体と対象、確からしさ、否定と
例外、量化子、因果、仮定、比較の向き、数値と条件、引用の結び付き、意味を変える単複。

## 差分

```bash
sh paper/build.sh
```

`paper/main.pdf` と `paper/diff.pdf` ができる。差分は追加が青字で、削除は出ない。
比較元は `paper/old.tex`。ここへのコピーは指示があったときだけ行う。

色は `paper/diff-preamble.tex` の `diffcolor` を変える。数式でコンパイルが通らない
ときは `--math-markup=whole` を足す。
