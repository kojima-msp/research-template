# 論文の執筆

## 進め方

- 文法や表現の修正は edit を出すだけでよい。説明も和訳も添えない。
- コンパイルは、大幅な修正をしたときだけ行う。文法や表現の修正では行わない。

## 参照

- 用語・言い回し・節の構成は、`~/paper/` にある添削済みの tex に合わせる (`ja/` 和文、
  `en/` 英文)。該当する表現が無い場合にだけ新しく書く。

## 用語

- 造語を作らない。分野の標準用語を使うか、数式で定義する。
- 定義していない語を本文で使わない。

## 数式

- まず式を示し、その後に各文字を説明する。
- 式が一行なら `equation` を使う。式の前に改行を入れない。

## 和文の細部

- 段落頭の「また」を使わない。
- 節をまたぐ「上記の」「前節で述べたように」を使わない。
- 和文中のコロンを使わない。

## 削るもの

- 内部的な言い訳を散文で書かない。式で書けば十分。
- 手法の章で説明済みの内容の再説明。
- 長すぎる一文。主張の補助になっていない説明。

## 主張

- 考察で自分の結果を弱めて終わらせない。事実を歪めない範囲で主張が成立する形に整理する。

## 図表

- `out/img/` からコピーして `paper/` に置く。元を直接参照しない。
- どの commit の結果を使ったかを `paper/RESULTS.md` に記録する。
